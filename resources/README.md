# Resources

One place for the books, papers and lectures that the roadmaps, cheat sheets and projects refer to.

| File | Covers |
|---|---|
| [Books](books.md) | Textbooks by topic, with verdicts, levels, cost tags and the phases that use them |
| [Papers](papers.md) | Academic articles by topic, with the place each one is used in this repo |
| [Lectures and courses](lectures.md) | Free course materials, with confirmed links and courses whose links still need checking |

## How to use this folder

- Start with the roadmap for your role. Each phase names one primary resource.
- Use this folder to look up a reference, or to see every resource for a topic in one place.
- If a resource appears in a roadmap but not here, that is a gap to fix. The roadmaps are the authority on what to study first.

## Adding a resource

Follow [CONTRIBUTING.md](../CONTRIBUTING.md). Every entry needs a verdict, a difficulty level and a cost tag. Papers need the full citation and a note on where the paper is used.
