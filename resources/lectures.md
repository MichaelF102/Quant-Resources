## How to use lectures

- **Pair each lecture set with problems.** Watching is not the same as solving. Use the interview banks or the project specs.
- **Take notes in your own words.** A written summary of each lecture helps you find gaps.
- **Stop when the lecture stops teaching you something.** A two-hour lecture with one useful idea is not worth the full two hours.

See the [books list](books.md) for the textbooks that go with these courses.
