# Roadmaps

Phased plans for the four main quant roles. Each roadmap gives a time budget, one primary resource and one backup per phase, a checkpoint project for each phase, and a portfolio checklist for the end.

## Compare the paths

| Roadmap | Core skills | Interviews lean on | Checkpoints built in | Time |
|---|---|---|---|---|
| [Quant Researcher](quant-researcher.md) | Probability, statistics, time series, derivatives, ML, portfolio construction | Probability, statistics, derivatives, research design | Projects 01, 02, 03, 05, 07, 09, 13, plus fixed income and credit elective | ~7–9 months |
| [Quant Developer](quant-developer.md) | C++, data structures, OS, networking, performance, market protocols | C++, systems, order book design, coding | Custom vector, order book, lock-free queue, ITCH parser, event-driven backtester | ~8–10 months |
| [Quant Trader](quant-trader.md) | Mental math, probability, options intuition, market making, microstructure | Mental math, expected value, games, options and volatility | Projects 02, 03, 10, 11, 12, 14, and a competition or paper-trading record | ~6–8 months |
| [Risk and Model Validation](risk-model-validation.md) | Statistics, pricing model limits, VaR and backtesting, credit risk, governance, regulation | Statistics, risk measures, model judgement, regulation | Projects 01, 12, 14, a Merton calculator, and a validation report | ~6–8 months |

## Which path?

- **You like proofs, data and research design** and want to find signals: start with the [Quant Researcher](quant-researcher.md) roadmap.
- **You like systems, speed and low-level code:** start with the [Quant Developer](quant-developer.md) roadmap. If you're aiming at research platforms rather than HFT, use the research platform track at the end of it.
- **You like quick decisions under uncertainty and games:** start with the [Quant Trader](quant-trader.md) roadmap. Begin the mental-math drills on day one.
- **You prefer checking models and measuring risk to building them:** start with the [Risk and Model Validation](risk-model-validation.md) roadmap. It is also a stable entry route into front-office work.

Not sure? Start with **Phase 1 of the Quant Researcher roadmap**. Probability and statistics are shared by every role, and [Project 01](../projects/01-monte-carlo-pricer/) is the first checkpoint for all of them.

## Conventions used in the roadmaps

- **Primary and backup resources.** Do the primary. Use the backup only when the primary doesn't click.
- **Checkpoint.** A phase isn't done until you've built its checkpoint. Projects are in the [project ladder](../projects/README.md).
- **Skip for now.** Each phase names what to leave until later, so you don't spend time on it too early.
- **Cost and difficulty tags.** 🆓 free, 💸 paid. 🟢 beginner, 🟡 intermediate, 🔴 advanced.
