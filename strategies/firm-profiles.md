# Firm profiles

*Last reviewed: Oct 2026*

What each firm's own website says about its business, with the date the page was checked. These are public, broad descriptions. They are not claims about any firm's trading strategies, which are generally confidential.

Where the source article attributed a description that the firm's own page did not support, the difference is noted.

## How to read this file

- **Public description:** a summary of the firm's own website. Quoted phrases are from that page.
- **Checked:** the date the page was confirmed to load.
- **Note:** anything the source article said that the page did not support, or that could not be checked.

Firm descriptions change. Check the page before relying on one.

## Using this file

- Cite a firm's public description, not a strategy. For example, "Two Sigma describes itself as a quantitative investment and trading company" is supported. "Two Sigma uses gradient boosting for returns" is not supported by its public description.
- When a source makes a claim about a firm, check the firm's own page first. If the page does not say it, record that.
- Firm associations of strategy families (for example, which firm is said to run statistical arbitrage) are the source article's. They are not established by the firm pages reviewed here, so treat them as the article's claims.
